# 文件属性查改器 V2.0

纯 C++ / Win32 桌面程序，一套源码生成 32/64 位单文件绿色版。原版 V1.2 和 REA 证据保留在根目录。

## 运行

- `dist/x64/文件属性查改器.exe`：64 位 Windows。
- `dist/x86/文件属性查改器.exe`：32 位版，也可运行于 64 位 Windows。
- 无需安装 .NET、Python、Office 或 VC 运行库。应用本身不保存配置、不写应用注册表项；Windows 自身仍可能维护系统缓存或最近访问记录。

## 使用

1. 拖放文件/文件夹，或点击添加按钮；支持多个命令行路径。勾选“包含子文件夹”可递归收集，跳过目录链接防止循环。重复路径自动合并。
2. 左侧可 Ctrl/Shift 多选、Ctrl+A 全选；Delete 只移除列表项，不删除文件。
3. 右侧使用系统列表控件，提供可见滚动条。搜索名称/内容/字段标识，或仅显示可修改项。选择一行后，下方显示完整内容并可选中复制。右键或 Ctrl+C 复制单行值，“复制属性”复制选中文件的完整清单。
4. 双击“可修改”项或点击“修改此项”，输入新值并保存。多选文件可将同一字段批量应用，逐文件检查是否支持；不支持的文件记录失败，不阻止其余文件。结果按钮可查看并复制完整成功/失败记录。
5. MD5/SHA-256 默认关闭。勾选后添加会自动计算；也可对选中文件点击“计算哈希”，无选择时计算全列表。两种哈希一次读取完成，1 MiB 缓冲，无 1 GiB 上限；显示字节进度并支持取消。读取失败不返回部分摘要。
6. 导出全部已载入文件：TXT、CSV、真正的 XLSX。单文件默认名取自该文件，多文件名以第一个文件名和数量组成。TXT/CSV 为 UTF-8 BOM；CSV 防公式注入可能添加前置单引号，推荐用 XLSX 保留文本类型、版本号、长数字和摘要。

## 修改能力与边界

| 内容 | 支持方式 |
|---|---|
| 只读、隐藏、系统、存档 | 设置单独属性位，保留其他标志 |
| 文件创建/修改/访问时间 | Windows 文件系统时间；输入 `YYYY-MM-DD HH:MM:SS` 本地时间 |
| 文件所有者 | 输入 `计算机名\账户` 或域账户；需要相应权限，不自动提权 |
| EXE/DLL 的版本、公司、说明等 | 修改已有 VERSIONINFO 的字符串/固定版本；保留其他资源及语言。无版本资源的文件不凭空添加 |
| Word/Excel/PowerPoint Open XML | 直接读写核心元数据：标题、主题、作者、关键词、备注、最后保存者、文档创建/最后保存时间、修订号、类别。支持 docx/docm/dotx/dotm、xlsx/xlsm/xltx/xltm、pptx/pptm/potx/potm/ppsx/ppsm |
| 图片 EXIF、音频标签、旧式文档及其他格式 | 枚举 Windows Property System 字段；由系统中具体文件处理器决定可写性，写入后回读验证。不支持的项显示只读；两个架构可用处理器可能不同 |
| 照片拍摄时间 | 来自文件内部 EXIF/Shell 属性，和文件复制到电脑的日期分开 |
| 文档“首次编辑时间” | 本版对应文档创建时间；不是可恢复的真实编辑历史。总编辑时间、页数、字数等显示处理器/文档现有值，不把这些统计字段伪装成任意可编辑文本 |
| 源路径、计算机 | 显示当前路径、当前计算机及文件已有 Zone.Identifier 下载来源；不能恢复文件中没有保留的历史来源 |

内容属性编辑在同目录临时副本中执行，校验后替换原件，生成名称包含 `.fpv-{GUID}.bak` 的原件备份。备份会占用额外磁盘空间，不会自动删除。替换失败时报告原路径、备份路径和保留副本；原路径缺失时尝试从备份恢复。文件系统标志、时间、所有者直接修改，不生成内容备份。请根据操作记录恢复这些属性。

关闭使用该文件的其他软件后再编辑。文件只读时需先取消只读。内容修改会改变校验值，可能破坏 EXE、Office 或其他文件的数字签名；界面要求确认这一影响。拒绝直接改写重解析点和多硬链接文件的内容；EFS 加密文件暂不改写，避免产生明文临时副本。临时副本沿用原 DACL，并在替换前保持原所有者；无法保持时取消保存。加密/损坏/缺少核心属性的 Office 文件不强行写入。

签名使用 WinVerifyTrust **离线**验证，不检查吊销及目录签名；界面分别说明通过、失败和未发现嵌入签名。类型说明来自系统关联、扩展名和有限常见格式文件头探测，不能识别所有未知/伪装格式。JPEG 等元数据处理器可能重写文件内容，备份用于恢复原件。

## 构建与测试

需要 Visual Studio 2022 的 C++ 桌面工具及 Windows 10 SDK。推荐在项目根目录运行：

```powershell
.\build.ps1 -Architecture all -Test
# 可选 x86 或 x64；额外测试 >1 GiB 稀疏文件及中途取消
.\build\x64\Release\property_tests.exe --large
```

脚本自动定位工具链，`/MT` 静态运行库，生成物放入 `build` 和 `dist`。也提供 CMakeLists.txt，可用 Visual Studio CMake 打开；CTest 的工作目录设为项目根目录。

源文件职责：`core.cpp` 文件/哈希/OPC/Office；`inspect.cpp` 属性与类型/签名；`edit.cpp` 安全写入与文件系统修改；`version.cpp` PE 版本资源；`export.cpp` 导出；`app.cpp` 原生界面与工作线程。

API 按 Windows 7 下限编写，PE 子系统版本 6.1；Windows 7/8/10/11 的实际兼容性需要分别运行验证，不能由当前 Windows 11 上的测试推定。属性处理器由系统提供，可能有自身延迟；取消会在当前处理器调用完成后生效，不强制终止写入。
