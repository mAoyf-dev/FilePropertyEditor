# V2.1.1 更新检测限流修复

## 根因与范围
2026-11-19 匿名 API 实际返回 HTTP 403、X-RateLimit-Remaining: 0；认证 gh 查询表明 V2.1.0 发布及附件存在。原更新检测只支持 API，因此配额耗尽时直接失败。

## 改动
- src/update.cpp/h：保留 API 查询；仅在 HTTP 403/429 时降级至同仓库 /releases/latest 和 expanded_assets。严格数字版本、HTTPS/重定向白名单、2 MiB 内容限制；公开页必须提供合法 SHA-256，选中附件通过 HEAD 取得准确大小，再复用原下载保护。
- 降级后本进程暂停 API 请求一小时，不重试耗尽的接口；系统信任和证书校验保持开启。
- tests/update_tests.cpp：公开页附件解析测试；--public 强制覆盖公开页集成；异常输出明确原因。版本与资源更新至2.1.1。
